# Production resident worker gate, before measurement

Requires all plain SDK three-round content/model gates and exact boundary outputs. Compare actual current stock libncnn against the stripped pad-only candidate, using byte-identical existing libmanyue_realesr/libomp/models and chunk1/tile400/jobs1. Candidate enables only MANYUE_FUSE_PAD1=1; weights/arithmetic/output2x unchanged. Two source images690x901color /635x831syntheticline, both six tiles and nonmultiple edges; legal CC-BY source and locally generated content only. Lossless PNG gives unambiguous pixel comparison including all seams. This does not replace losslessWebP reader validation.

Three AB/BA/AB rounds for each model and content; two warmups +three measured requests in each resident process; load once, assert modelLoads0 afterwards, backendGPU/tile400/dimensions, exactRGBA including seams and no error. Record before/after thermal/battery and retain all samples. Gate EACH model/content: median total-time reduction>=5%, no paired regression>5%, same direction>=2/3. Show per-round inference and full decode/infer/output wall time; do not select best round. Any new crash/wrong pixels is failure. Thermal-state transitions or extreme ordering drift require qualification, not automatic adoption. This stage is fullNative only, no reader/input/Surface/long-reading/watts claim.

Strip only symbol/debug sections with NDK llvm-strip; record both hashes and prove unchanged PT_LOAD bytes except ELF section-table metadata fields. No second shader change or precision/weight change. APK integration is a later candidate step only if gate passes; formal sustained performance/energy release remains unaccepted until live matched reading.
