# v93 isolated, rejected feasibility prototype

Do not apply this graph/library to production. No accepted speed or energy change. See ../../../docs/QUALITY2_NATIVE_V93_EXPERIMENT.md and same-computer work/quality2/native-profile-v93-20261018/ for numerical reports, compiler configuration, converter and run scripts. Original ncnn20241226 BSD-3-Clause source is pinned by SHA256 b2145f7b01422f5ee66777d1c2c29de935191ed39865193951e1a7228202a6c1. Patch metadata lists original/candidate file hashes; original model weights remain untouched. packHalf and storage-cast are alternative revisions, never apply both patches.

The public-API probes are executable investigations only. compute_probe retains the existing sixteen graph boundaries and measures wall/thread-CPU spans, not pure GPU time. readback_probe checks byte identity and actual Vulkan memory flags using the same RGB byte layout as RealSR output. Host linking: pinned stock ncnn20241226 headers/import library, Zig0.13 x86_64-windows-gnu, -std=c++11 -O2. ARM64: NDK29 clang++ --target=aarch64-linux-android26 -fPIE -pie -static-libstdc++, stock libncnn.so/libomp.so, -lvulkan -llog -landroid. Results on NVIDIA do not establish Adreno correctness, energy or reader performance.
