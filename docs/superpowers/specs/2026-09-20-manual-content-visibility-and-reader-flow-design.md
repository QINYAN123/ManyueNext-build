# ManyueNext：独立内容属性与阅读流程设计

日期：2026-09-20

状态：用户已确认，进入实现

## 1. 目标与边界

这次改动的目标不是把应用做成成人向应用，而是让应用启动后呈现正常漫画阅读器的默认视图，同时保留用户自行查看完整内容的入口。

附件截图仅作为交互参考：

- 书架长按漫画后可设置独立的内容属性；普通分类继续保留给用户组织书架。
- 书架和图源列表提供小型筛选入口，默认关闭成人内容，打开后显示完整内容。
- 漫画详情页的“继续”和书架点击都应落到上次阅读的章节与页码。
- 阅读器控制栏显示真实检测到的原图尺寸、超分后实际输出尺寸，并提供进入漫画目录的按钮。

本次不改变普通分类的含义，也不依赖固定 source ID 来永久决定用户是否能看到内容。

实现约束：优先复用现有原生流程和控件，不新造重复页面。具体复用书架现有筛选面板与长按选择模式、图源现有长按选项弹窗、阅读器现有 `ReaderAppBars`、Material 图标和继续阅读导航；新增内容主要是属性状态、筛选条件、持久化和回调接线。

## 2. 内容属性模型

### 漫画

在 `mangas` 表增加独立的 `content_rating_override` 字段，并在领域层增加三态属性：

- `AUTO`：该漫画跟随全局自动识别开关；默认值。
- `NORMAL`：用户手动覆盖自动判断，始终按正常内容显示。
- `ADULT`：用户手动标记为成人内容；默认隐藏，打开筛选开关后显示。

另增加全局持久化开关“自动识别成人内容”，默认开启。开关开启时，只有 `AUTO` 漫画会使用已有内容警告、漫画标签等信号判断成人；开关关闭时，`AUTO` 漫画不再因为自动识别而隐藏，之后由用户逐个手动归类。手动 `NORMAL` 和 `ADULT` 始终优先于自动识别开关。

现有普通分类、收藏分类、下载分类均不参与成人隐藏逻辑。长按漫画的操作中增加独立的“内容属性”入口，提供“跟随自动 / 正常 / 成人”三个选项；普通的“设置分类”保持原样。批量选择时允许批量设置该属性。

### 图源

图源不适合写入漫画数据库，使用持久化的 source-id 属性覆盖表：

- `AUTO`：跟随全局自动识别开关，开启时使用扩展内容警告作为默认判断，关闭时按正常内容处理，等待用户手动归类。
- `NORMAL`：手动覆盖为正常图源。
- `ADULT`：手动标记为成人图源。

图源长按菜单增加同样的内容属性入口。图源列表、单个图源浏览页、云收藏页共享当前进程的“显示成人内容”开关；开关默认关闭，重启后恢复关闭。内容属性本身持久保存。

既有硬编码成人 source ID 不再直接决定显示结果，只能作为 `AUTO` 的一个识别信号；手动属性优先级最高。全局自动识别开关关闭后，不再依赖这些自动识别结果。

## 3. 默认显示与筛选

统一使用以下判断：

1. “显示成人内容”关闭：显示正常内容，隐藏被自动判断或手动标记为成人的内容。
2. “显示成人内容”打开：显示全部内容。
3. “自动识别成人内容”关闭：不再根据自动标签隐藏 `AUTO` 条目，只隐藏用户手动标记为成人的条目。
4. 手动标记“正常”的条目，即使来源或标签被识别为成人，也显示在默认视图。
5. 未分类的新漫画使用 `AUTO`，而不是强制写成成人。

筛选开关沿用现有筛选面板的视觉风格，文案改为明确的“显示成人内容”。另外在浏览/安全设置中提供持久化的“自动识别成人内容”开关。不再使用“本次运行显示 R18 内容”这种只按全局规则过滤的语义。

书架、图源列表和云收藏使用同一个进程级开关，但各自的条目判断使用自己的漫画/图源属性。直接打开已经明确知道的漫画或章节不被这个列表筛选开关阻断。

## 4. 书架标签

书架从已收藏漫画的 `genre` 自动汇总标签，不复制、不修改源数据，也不占用普通分类。

- 在书架筛选面板增加动态“标签”区域。
- 标签来自当前收藏内容，去重并按本地化排序。
- 点击一个标签后，只显示包含该标签的漫画；清除标签恢复全部结果。
- 成人内容隐藏时，标签汇总也只从当前可见内容生成；打开成人开关后，成人漫画的标签一并出现。
- 标签筛选与普通分类、下载、未读、已完成等过滤条件叠加。

## 5. 阅读入口与断点续读

### 书架点击

- 书架普通点击优先打开该漫画最近一次未完成阅读的章节。
- 打开时复用现有章节进度字段，恢复到上次保存的页码，而不是从章节第一页开始。
- 没有可继续章节时，回退到漫画目录页。
- 长按仍进入选择模式；目录入口和普通分类操作不丢失。

### 继续按钮

漫画详情页和书架上的“继续”按钮使用同一个阅读目标解析器，保证章节选择和页码恢复一致。章节已读完但仍有更早断点时，按现有阅读历史规则选择最近一次未完成位置。

## 6. 阅读器界面

### 尺寸信息

保留“只有半透明控制栏显示时才显示信息”的行为，并将页面信息扩展为：

- `原图 W × H`：从源图片实际解码/读取到的尺寸。
- `超分后 W × H`：从超分输出文件或 Bitmap 实际读取到的尺寸。

超分后尺寸不得通过倍率乘法推算；如果输出尚未完成显示“读取中”，如果读取失败显示“未知”。页面切换时两组尺寸随当前页更新。

### 漫画目录按钮

在右上角溢出菜单旁增加符合现有 Material 风格的目录按钮。点击后调用现有的漫画目录导航，回到该漫画的详情/章节列表；不改变系统返回键和阅读器关闭行为。

## 7. 数据迁移与兼容

- 新增 SQLDelight 数据库迁移，为现有漫画写入 `AUTO` 默认值。
- Manga、MangaUpdate、Repository、备份创建与恢复链路同步增加字段。
- 自动识别开关使用独立 preference key，默认开启；关闭后不清除用户已有的手动 NORMAL/ADULT 覆盖值。
- 旧数据不自动改成成人；只有自动识别结果或用户手动属性会影响默认显示。
- source 属性使用新 preference key；旧版本没有该键时按 `AUTO` 处理。
- 不改普通分类表和用户已有分类名称。

## 8. 测试与验收

增加或更新以下测试：

- 内容属性策略：自动、手动正常、手动成人、未分类默认值和显示开关优先级。
- 图源属性策略：自动识别、手动覆盖、进程开关重置。
- 数据库迁移及 Manga 映射/备份默认值。
- 书架标签汇总、选择和与其他筛选叠加。
- 书架点击和继续按钮解析到正确章节及 `lastPageRead`。
- 阅读器原图/超分实际尺寸显示和不可用状态。
- 目录按钮回调及现有阅读器工具栏回归。

最后执行定向单元测试、完整 debug APK 构建、APK 静态检查，并在有设备连接时补做安装和真机流程；没有设备时明确记录未完成真机验收。

## 9. 实现顺序

1. 领域枚举、数据库迁移、Repository/备份映射。
2. 自动判断与手动覆盖策略、图源 preference 存储。
3. 书架和图源列表的内容属性入口及成人筛选开关。
4. 书架动态标签筛选。
5. 统一阅读目标解析与书架点击行为。
6. 阅读器实际超分尺寸传递和目录按钮。
7. 测试、构建、静态与真机验收。

每一步先沿用现有界面入口，再补最小必要的状态和数据流；只有现有组件无法承载时才增加新的 Compose 组件或页面。
