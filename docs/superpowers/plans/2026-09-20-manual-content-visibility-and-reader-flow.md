# ManyueNext 源码改造实施计划（修订版）

> 执行者使用 executing-plans 按任务推进。用户已授权基于现有源码实现全部功能；本文件供审阅，不增加重复授权关卡。

**目标：** 在现有应用中实现可人工纠正的内容显示控制、书架标签筛选、准确续读和真实图像尺寸，并交付 APK 与配套源码 ZIP。

**架构：** 复用现有 Compose 页面、SQLDelight 数据、偏好存储和阅读器。统一内容判定、阅读目标解析及页面图像元数据，页面仅接入这些规则，不各自复制逻辑。

**技术：** Kotlin、Jetpack Compose、SQLDelight、现有 Android/Manyue 图像管线。

**依据：** 用户本次及此前消息优先；旧设计文档中“最近未完成章节”等与本文件冲突的描述，由本文件修正。

## 一、用户实际看到的功能

### 1. 两个独立开关，加上每个条目的手动覆盖

- “显示隐藏内容”：关闭时显示正常视图，打开时显示全部。冷启动默认关闭；旋转屏幕、切换页面不重置。普通后台切换不算重启。
- “AUTO 自动识别”：持久保存，默认打开。关闭后不再使用标签、图源 warning 或硬编码 source ID 自动隐藏内容。
- 每部漫画、每个图源都有独立的内容属性，操作选项为“跟随 AUTO / 正常（默认显示）/ 成人（默认隐藏）”。AUTO 是全局识别开关；条目的“跟随 AUTO”表示没有人工覆盖。
- 人工覆盖长期保存，优先于自动判断；普通分类完全不参与此判定。
- “显示隐藏内容”始终可以临时放出全部内容，方便找回隐藏条目并改正误判。开关本身始终可访问。

| 条目设置 | AUTO 开启、显示隐藏关闭 | AUTO 关闭、显示隐藏关闭 | 显示隐藏开启 |
| --- | --- | --- | --- |
| 手动正常 | 显示 | 显示 | 显示 |
| 手动成人 | 隐藏 | 隐藏 | 显示 |
| 跟随 AUTO | 按识别结果 | 显示 | 显示 |

漫画和图源分别保存属性。漫画的人工正常覆盖可以让该漫画留在书架，即使图源默认隐藏；隐藏图源不删除漫画、不卸载扩展、不暂停更新下载。漫画跟随 AUTO 时，来源属性参与自动判定，但漫画自身明确的成人标签仍可判为成人。把图源改成正常不会批量重写漫画属性。AUTO 关闭时，只有条目自身的人工成人标记导致隐藏。

识别仅使用现有元数据和精确规范化标签，不增加联网 AI、图片识别或标题猜测。“自动”不能保证正确，因此手动覆盖是完整的一等功能。

### 2. 界面入口与统一显示

- 书架：复用长按多选，在现有操作菜单添加“内容属性”，支持批量操作。原“设置分类”保持原功能。
- 图源：复用长按菜单添加内容属性；复用筛选入口放置显示开关。
- 设置：放置 AUTO 开关及简短说明；书架和浏览的显示开关操作同一个会话状态。
- 漫画详情提供内容属性入口，便于修正不在书架中的漫画。
- 检查书架、历史、更新、图源列表、图源浏览、全局搜索、云收藏、扩展目录和迁移候选等可展示内容的入口。凡涉及同一漫画/图源，使用统一判定。已有扩展内容警告过滤不能先把用户手动放出的图源截掉。
- 收起隐藏内容时，当前列表、搜索结果、标签和可见数量同步刷新；清除隐藏条目的选择状态。保持底层收藏、历史、下载和更新数据。
- 不把这个功能做成密码锁或安全隔离：已进入的阅读器不强制退出。它负责启动默认视图及内容列表的显示。

### 3. 收藏标签

从已收藏漫画的 genre 派生书架标签，不创建普通分类、不修改源标签。提供可点击的标签筛选入口及“全部/清除”；第一版单标签筛选，与已有分类和其他过滤条件取交集。

标签只从通过内容可见性判断的收藏漫画生成，但不受当前选中标签反向限制，避免选中后其他标签消失。忽略空标签、合并前后空白和大小写重复项，保留可读名称。隐藏开关使选中标签不再存在时，清除该标签并刷新结果。没有标签时不伪造分类。

### 4. 继续阅读必须回到最后位置

书架点击与详情“继续”优先恢复最近实际阅读的章节和页码，包括已经标记读完的章节。不能用“最早未读”或“最近未完成”替代最后位置。

- 有有效阅读记录：恢复其 chapterId 与 lastPageRead，不因章节排序、已读状态或筛选改变而跳到别章。
- 没有记录：复用原有开始阅读/首个可读章节逻辑；没有章节则进入目录。
- 最后章节已被删除：使用已有可读章节回退并提示，不能静默打开随机章节。
- 页码越界：加载实际页数后夹到有效范围；UI 页码与内部零基索引只转换一次。
- 页面切换、离开阅读器和正常后台切换及时保存进度；不承诺系统瞬间强杀前尚未落盘的状态。
- 书架长按保留选择功能，并保留“漫画详情/目录”入口。

### 5. 阅读器

在半透明顶栏左侧标题区域下方显示“原图 W × H”和“当前图像 W × H”，增强实际生效时明确标注“超分后”。右上角三点菜单旁添加目录图标，调用已有打开漫画详情/章节列表的导航。

原图尺寸来自增强前实际图像；当前图像尺寸来自本页当前真正交给渲染器的最终资源。像素资源尺寸与屏幕上缩放占用的像素不同，不能把 View 大小称为超分分辨率。

- Manyue 输出有后续缩放和分块，检测最终输出，不使用模型倍率或预设目标值。
- 分块宽度一致且完整时，可由实测分块宽度和高度总和得到整图尺寸；分块缺失或不一致不报告成功尺寸。
- 缓存命中也要验证实际缓存资源；正在计算但仍显示原图时，报告当前为原图并显示处理状态。
- 关闭、失败、不支持超分时显示真实状态，不伪装为“读取中”或超分成功。
- 分页、条漫和 WebGPU 路径分别接线；GPU 路径读取实际纹理/输出资源尺寸，取不到则明确不可用。
- 元数据绑定章节、页和增强请求身份；快速翻页、模式切换后的旧回调不得污染当前页。

## 三、实施任务与验证

### A. 内容模型与持久化

涉及 domain 的 Manga/MangaUpdate；data 的 mangas.sq、MangaMapper、MangaRepositoryImpl；app 的 BackupManga 与备份创建/恢复链路；ui/adult 策略及偏好存储。

- [ ] 核对最新 migration 编号及备份 proto 编号后追加字段，不能直接假定旧计划的编号仍空闲。
- [ ] 新增稳定编码的漫画覆盖枚举：0 跟随、1 正常、2 成人；异常值回退跟随，不用 enum ordinal 作为持久化协议。
- [ ] 图源按稳定 sourceId 保存覆盖；AUTO 开关持久化，显示隐藏开关仅在进程内保存。
- [ ] 统一策略输入：条目人工覆盖、AUTO 状态、自动判定结果、会话显示状态；输出可见性与判定原因。识别结果不写成人工覆盖字段。
- [ ] 为云收藏等非本地漫画通过稳定 sourceId + 源内漫画身份解析已保存覆盖，避免同一漫画在书架正常、搜索仍隐藏；不按标题匹配。
- [ ] 验证矩阵全组合、旧数据库升级、旧备份恢复、新备份往返、源元数据更新不覆盖人工设置。图源偏好与 AUTO 设置纳入现有设置备份路径。

核心规则：
```kotlin
fun shouldShow(showHidden: Boolean, autoEnabled: Boolean, override: RatingOverride, detectedAdult: Boolean): Boolean =
    showHidden || when (override) {
        RatingOverride.NORMAL -> true
        RatingOverride.ADULT -> false
        RatingOverride.FOLLOW_AUTO -> !autoEnabled || !detectedAdult
    }
```

## 四、完成判定与实施边界

按 A → B → C → D → E → F 执行，先复用原生能力，再补缺失数据和回调；不以新增按钮数量作为完成标准。最终必须同时达到：启动默认隐藏、人工可纠正、AUTO 可关闭、标签可筛选、继续准确到章页、真实输出尺寸可核验、目录可进入、APK 和源码相互对应。

五个重点回归风险分别在上述任务验证：上游过滤吞掉人工正常条目（B）；历史/更新泄露隐藏项（B）；最近已读章被错误跳过（D）；分块/缓存产生假尺寸或旧页尺寸（E）；源码包漏掉未提交连接器或 APK 无法覆盖旧包（F）。

本次计划不承诺仅靠静态标签识别所有成人内容，也不把隐藏功能扩展为应用锁。普通分类、收藏、阅读记录及后台下载仍按原有数据模型工作。
